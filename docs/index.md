# От данных к проверяемому результату

<p class="lead">Один CSV. Один конвейер. Результат, происхождение которого можно проверить.</p>

**Артём Солопов · Проектирование и развёртывание веб-решений в экосистеме Python**

Учебная работа исследует способы публикации результатов вычислений и реализует
воспроизводимый конвейер на Python и Material for MkDocs.

!!! info "Объём работы"
    Основной ход работы, исследование **T2** и практика **P3**, согласно требованиям отчёта.
    Фактический статус внешней публикации указан в [отчёте](report.md).
