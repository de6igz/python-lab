# Набор данных timings-v1

Синтетические учебные данные, подготовленные для задания 1. Это не измерения
реального компьютера и не доказательство производительности конкретной системы.
20 наблюдений: время обработки одинаковой условной нагрузки для 1, 2, 4 и 8
рабочих потоков, по 5 повторов. `seconds` — секунды, `workers` — число потоков,
`run` — номер повтора внутри группы. Пропусков нет; время строго положительное.
Лицензия данных — CC0-1.0. При изменении CSV изменяется SHA-256 набора данных.
